# Cinematic landing (`apps/web`)

Angled bird's-eye of a luxury villa, then a seamless walk through garden → entrance →
living room → kitchen → bedroom, each room a Locus vignette. This site never talks to a
Home Core.

Stack: TypeScript + Vite + Three.js + GSAP. HUD is DOM overlay.
See `docs/techstack.md` §13.
